To use the provided NMS logo on the Dashboard:
1. Save the logo image file as Resources\NMS_logo.png (recommended PNG with transparent background).
2. The project is configured to copy images under Resources to the app output.
3. Run the application; the Dashboard will load the image at runtime (pack://siteoforigin:,,,/Resources/NMS_logo.png).

If the image does not appear, verify the file name and that it is included in source control or present in the build output folder.
