Important recommendation before adding this to your software

Because you specifically want “open free software,” I recommend that you first decide which meaning you want:

Freeware: Users can use it for free, but you retain control over modification and redistribution.
Open source with MIT License: Users can use, modify, distribute, and commercially reuse the source subject to the license conditions.
Open source with GPL: Users can modify and redistribute it, but distributed derivative works generally remain subject to GPL requirements.

If your intention is “anyone can freely use my Naqeebs Accounting System, including businesses, and the source code will be available on GitHub”, I can next prepare a coordinated LICENSE + EULA + GitHub README copyright section so the three don't contradict one another.

Drafting approach

I deliberately separated free use, open-source rights, branding, warranty, data backup responsibility, and optional paid support. This is important because making the accounting software free does not necessarily mean every service, trademark, or piece of branding must also be unrestricted.
